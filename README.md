

\# 📚 StudyLens AI



StudyLens AI is a smart study assistant that helps students

manage and understand their study notes.



\## Features

\- Upload study notes

\- View text notes

\- Generate short summaries

\- Get quick study tips



\## Technologies Used

\- Python

\- Streamlit

\- PyPDF



\## How to Run



1\. Install Python.

2\. Install the required libraries:



&#x20;  pip install -r requirements.txt



3\. Run the application:



&#x20;  streamlit run app.py
